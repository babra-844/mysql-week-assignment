
# Library Management Database

## Project Description
This project creates a MySQL database for a
Library Management System.

## Database Name
library_management

## SQL Commands Used
- CREATE DATABASE
- USE
- SHOW DATABASES
- SELECT DATABASE()

## How to Run
1. Open MySQL Workbench or Terminal.
2. Connect to the MySQL server.
3. Execute the commands in database.sql.
4. Verify that the database was created successfully.
